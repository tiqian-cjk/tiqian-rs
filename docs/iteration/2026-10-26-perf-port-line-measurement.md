# 历史行测量优化迁移

## 范围

基于 main `d2f467f`，迁移 new 保留的重复计宽、索引构造、压缩缓冲复用和 PushIn 提前筛选优化。
不迁移已撤回的 source 按需统计与空白表共享，不改变排版规则。

无 Tab、无分配的候选计宽原本为 O(1)。含 Tab 的逐候选测量仍可能重复访问 Tab，
最坏情况的二次复杂度未消除；本次不将已有优化描述为修复所有 O(n²) 路径。

## 测量方案

先构建并保存迁移前程序，再修改源码；迁移后以同配置两份程序交替测量。
使用默认 release、debug-info 关闭、greedy、宽度 672/360/960、20 次预热和 200 次采样。
分配单独使用 `--count-allocations`，其耗时不参与比较。只检查编译和基准，不运行测试或火焰图。
原始程序和输出位于系统临时目录 `tiqian-port-baseline-d2f467f`。

### 剩余复杂度

普通无 Tab 候选为 O(1) 查询，索引预处理为线性；本次消除了确认的重复计宽、排序与克隆。
含 Tab 的 greedy 逐候选测量在极端长行仍可能累计二次访问；repair 仍逐候选筛选整段机会集合。
这两项不在已迁移修复内，不声明已解决所有二次复杂度。
