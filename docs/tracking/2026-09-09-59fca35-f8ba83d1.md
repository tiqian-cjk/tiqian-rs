## 初步边界判断

`docs/key-differences.md` 已确认 Rust 使用 scalar source coordinate，且以 R0002 的统一富文本旁路模型替代 Kotlin
旧的 rich-text span 模型。因此所有 offset、selection、hit-test 和 rich-text 投影比较均需按可观察行为与已接受
差异判断，不能按 Kotlin UTF-16 代码结构机械移植。

上游 Android renderer、View、platform font catalog、Kotlin/Native callback、baseline profile 与宿主绘制行为默认不在
独立 Rust 排版核心的同步范围内。只有它们改变跨语言 `LayoutResult`、fixture、shaping evidence 或 Rust 公开输入输出时，
才扩大实施范围。

## 实施记录

### Rust 变动

- 新增 `src/core/layout_result_replay_index.rs`：从一个 `LayoutResult` 构造独立的只读 replay index；
	保持 R0001 scalar coordinate，并复用既有 interaction boundary、line lookup、source-stop 几何规则。
- 新增 `src/core/layout_paint_bounds.rs`：计算可见 occupied geometry 的 glyph、emphasis dot 与 ruby paint
	overhang，并提供由 engine hanging decision 授权的 clip edge。
- 新增 `src/core/fitted_line_pattern_geometry.rs`：生成端点对齐的 dotted center 与 dashed segment 坐标。
- 仅将 `layout_queries.rs` 的 `nearest_line_for_position`、`x_for_offset` 和 `offset_for_x` 提升为
	`pub(crate)`，使 replay query 与普通 query 使用同一算法；不改变原公开 API。
- 新增三组 core 回归并注册到 `tests/core/mod.rs`：5 项 line pattern 向量、replay index 的 R0002 rich-text /
	selection 几何，以及 glyph / dot / ruby overhang、离屏过滤和 hanging clip edge。
- 新增 desktop demo 消费：`DemoPageBlock` 保存与 `LayoutResult` 同生命周期的 replay index；Vello renderer
	从 index 读取 positioned cluster、glyph 与 rich-text segment。删除 renderer 内重复的 dash / dot 公式。
