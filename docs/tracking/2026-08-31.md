## 实施记录

### 移植首批回归测试

- Kotlin 依据：`SourceInteractionBoundariesCoverageTest`、`HyphenationLayoutTest.hyphenationIsOnByDefault`、`JustifierCompressionTest.nanSurplusEmitsNoAllocations`、`LineAdjustmentPushInTest` 的两个策略级断言，以及 `WidthIndependentAnnotationCacheTest` 的连续 resize parity 和随机序列。
- Rust 变动：新增 `tests/core/source_interaction_boundaries_coverage_test.rs`；扩展默认断词、压缩、PushIn 和缓存测试；`Justifier::compress` 在 surplus 为 NaN 时不再产生 allocation。
- 输入域差异：Kotlin 的孤立 UTF-16 surrogate 用例不能进入 Rust 的有效 UTF-8 `Text`；其余边界规则按原断言翻译，另以有效 supplementary scalar 覆盖代理对路径。
- 验证：`cargo test` 通过，269 个集成测试和 7 个库单元测试均成功；`git diff --check` 通过；文档措辞检查为 0 个命中。
- fixture parity：`tools/verify-all-fixtures.sh` 在 `ellipsis-and-dash` 失败。当前 Kotlin `HEAD` 为 `a551b708`，其 `079628ad` 在本轮审计终点之后新增 `ParagraphLanguageDashEllipsisContext` 的 role override dump；该行为不属于本轮选定的五项。
